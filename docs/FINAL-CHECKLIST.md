- [x] Сверить правило CPU около отметки и связь событий инцидента: Stage 49 —

  строк каждой категории, понижение уверенности при неполном журнале.

  общего журнала и стресс-сессии. Stage 49 проверяет именно инцидент,

- [x] Ограничить размер сообщений и выходных данных сборщика журнала ОС:

  Stage 47 — native/Python state, безопасный сброс повреждённого состояния,
  отдельная кнопка сброса без потери отчёта. Проверены повторный запуск,
  скрытые панели и синтетическая геометрия недоступного монитора.

- [ ] Проверить длительную работу: рост памяти, размер истории/отчётов,
